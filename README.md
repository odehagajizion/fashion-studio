# MvendyWendy Fashion Studio

A web workspace for running a fashion studio. This repository currently contains the first dashboard screen, built with Next.js, TypeScript, and CSS.

## Getting started

Requirements: Node.js 20.9 or newer and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the dashboard.

## Current state

The dashboard follows the supplied MvendyWendy reference and uses clearly labeled illustration data. Buttons and navigation provide lightweight feedback while the supporting workflows are being built. There is no database connection or authentication in this starter yet.

## Roadmap

1. Authentication and protected owner workspace
2. Supabase schema, business membership, and access policies
3. Customer records and measurement history
4. Orders, production tracking, payments, and fulfilment

## GitHub

To connect this local repository to GitHub, create an empty repository and run:

```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Do not commit `.env.local` or any service keys. The included `.gitignore` excludes local environment files.
